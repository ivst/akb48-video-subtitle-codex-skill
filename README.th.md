# Codex Skill สำหรับซับไตเติลวิดีโอ AKB48

[English](README.md) · [Русский](README.ru.md) · [한국어](README.ko.md) · [Español (LatAm)](README.es-419.md) · [Bahasa Indonesia](README.id.md) · [ไทย](README.th.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

**เอกสารภาษาไทยฉบับนี้ยังเป็นฉบับร่าง ควรให้เจ้าของภาษาตรวจทานก่อนใช้อ้างอิงเป็นฉบับสมบูรณ์**


เวิร์กโฟลว์ที่นำกลับมาใช้ได้สำหรับแปลและทำซับไตเติลวิดีโอ AKB48 และ 48 Group ช่วยให้ Codex แยกบทพูด การระบุผู้พูด เพลง และข้อความบนจอ ตรวจสอบการสะกดชื่อ และตรวจทานซับไตเติลกับวิดีโอที่เรนเดอร์แล้ว

ในรีโพซิทอรีมี Codex Skill โปรไฟล์ภาษาเริ่มต้น เครื่องมือตรวจ SRT เบื้องต้น คู่มือติดตั้ง และภาพตัวอย่างสองภาพจากตอนล่าสุดที่ทำซับภาษารัสเซีย โปรไฟล์ภาษารัสเซียอ้างอิงจากเวิร์กโฟลว์ที่ใช้กับวิดีโอเต็มตอนแล้ว โปรไฟล์ภาษาเกาหลีเป็นฉบับร่างที่ต้องให้เจ้าของภาษาตรวจ ส่วนภาษาอื่นเป็นจุดเริ่มต้นสำหรับผู้ร่วมพัฒนา

## การติดตั้งแบบย่อ

ต้องมี Git, Python 3.11 ขึ้นไป, FFmpeg/FFprobe ที่รองรับ libass และสิทธิ์ใช้งาน Codex คำสั่งด้านล่างโคลนรีโพซิทอรีและตรวจสอบเครื่องมือ แต่ไม่ได้ติดตั้งโปรแกรมที่จำเป็น เปิดโฟลเดอร์ที่โคลนใน Codex แล้วเริ่มแชตใหม่

```sh
git clone https://github.com/ivst/akb48-video-subtitle-codex-skill.git
cd akb48-video-subtitle-codex-skill
python .agents/skills/akb48-video-subtitles/scripts/check_environment.py --require-ass
```

## ติดตั้งสำหรับโปรเจกต์อื่น

หากต้องการใช้กับโปรเจกต์อื่น ให้คัดลอกโฟลเดอร์ `.agents/skills/akb48-video-subtitles/`ไปยังโฟลเดอร์ Skills ของผู้ใช้ Codex (โดยทั่วไปคือ `%USERPROFILE%\.codex\skills\akb48-video-subtitles` บน Windows หรือ `$CODEX_HOME/skills/akb48-video-subtitles` เมื่อกำหนด `CODEX_HOME`) จากนั้นเริ่มเซสชัน Codex ใหม่

## การตรวจสอบเพิ่มเติม

คำสั่ง SRT ด้านล่างใช้กับไฟล์ที่สร้างแล้ว ให้เปลี่ยนพาธตัวอย่างเป็นพาธจริง

```powershell
python .agents/skills/akb48-video-subtitles/scripts/check_environment.py
python .agents/skills/akb48-video-subtitles/scripts/check_srt.py path\to\dialogue.srt
```

สคริปต์ที่ให้มาใช้เฉพาะ Python standard library ไม่ต้องติดตั้งแพ็กเกจด้วย pip ดู [ข้อกำหนดทรัพยากร](.agents/skills/akb48-video-subtitles/references/resources.md)

## ขั้นตอนการทำงาน

1. ตรวจข้อความภาษาญี่ปุ่น และบันทึกป้าย ข้อความหัวเรื่อง กติกา และผลลัพธ์แยกกัน
2. แปลโดยใช้โปรไฟล์ภาษาที่เลือกและอภิธานศัพท์ประจำตอนที่ผ่านการตรวจแล้ว
3. ระบุผู้พูดเมื่อมีหลักฐานเพียงพอ หากไม่แน่ใจให้ใช้ป้ายกลาง ๆ
4. สร้าง SRT, ASS ที่จัดรูปแบบแล้ว และ/หรือ MP4 ตามที่ร้องขอ
5. ตรวจภาพตัวอย่างตลอดทั้งวิดีโอและตรวจไฟล์เรนเดอร์สุดท้าย เมื่อเหมาะสมให้ตรวจการถอดรหัส เวลา แพ็กเกจ และการคงเสียงต้นฉบับ

## ทรัพยากรที่ต้องใช้

สำหรับวิดีโอ 1080p ความยาว 20–40 นาที RAM 8 GB และ CPU 4 คอร์รุ่นใหม่เป็นจุดเริ่มต้นที่ใช้งานได้ หากทำ ASR ในเครื่อง RAM 16 GB และ CPU 6–8 คอร์จะสะดวกกว่า ควรมีพื้นที่ว่างประมาณ 10 GB สำหรับไฟล์ต้นฉบับ ไฟล์ชั่วคราว งานเรนเดอร์ และสำรองข้อมูล GPU เป็นตัวเลือก วิดีโอ 4K หรือบิตเรตสูงอาจต้องใช้ทรัพยากรมากขึ้น ตัวเลขนี้เป็นค่าประมาณ การใช้งานจริงขึ้นอยู่กับ codec โมเดล ASR และ encoder

## สิทธิ์และความเป็นส่วนตัว

ประมวลผลและเผยแพร่เฉพาะสื่อที่ได้รับอนุญาต อย่าใส่บทถอดเสียงของตอน ไฟล์ซับไตเติลฉบับเต็ม ข้อมูลรับรอง คุกกี้ หรืออภิธานศัพท์ส่วนตัวใน pull request สาธารณะหากไม่มีสิทธิ์เผยแพร่ ภาพตัวอย่างใช้แสดงรูปแบบซับไตเติล ส่วนสิทธิ์ในรายการยังเป็นของเจ้าของสิทธิ์

## การตรวจสอบวิดีโอทั้งหมด

รายงานวิดีโอรวมการถอดรหัสไฟล์ต้นฉบับและผลลัพธ์ทั้งหมด ข้อผิดพลาดของตัวถอดรหัส และการเปรียบเทียบจำนวนเฟรมที่ถอดรหัสจริง (`check_decode.py`) การคำนวณแฮชเสียงมีเวลาจำกัดตลอดกระบวนการและป้องกันการติดขัดของ pipe ใช้ `run_checks.py --media-timeout 1800` เพื่อกำหนดเวลาสูงสุดต่อไฟล์เป็นวินาที การเปรียบเทียบนี้สมมติว่าไม่มีการเปลี่ยนอัตราเฟรมโดยเจตนา

## ทางเลือก: การถอดเสียงภาษาญี่ปุ่นและคู่มือโดยละเอียด

**faster-whisper** ใช้สร้างร่างบทถอดเสียงภาษาญี่ปุ่นหรือตรวจเทียบซับที่มีอยู่ การแปลและการระบุผู้พูดเป็นขั้นตอนแยกกัน ติดตั้งในสภาพแวดล้อมแยก โหมด CPU ไม่จำเป็นต้องใช้ WSL หรือ GPU ดู [การติดตั้งและตัวอย่างถอดเสียงภาษาอังกฤษ](.agents/skills/akb48-video-subtitles/references/transcription.md) และ [คู่มือโดยละเอียดภาษาอังกฤษ](docs/workflow.en.md)
