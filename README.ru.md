Повторяемый процесс перевода роликов AKB48 и 48 Group: отдельный учёт диалогов, авторства реплик, песен и надписей; сверка имён; подготовка SRT/ASS и проверка вшитого видео.

В репозитории есть Codex skill, стартовые языковые профили, проверка SRT, инструкции по запуску и два примера оформления из последних русских выпусков. Русский профиль основан на обработке полных выпусков. Корейский профиль пока требует проверки носителем; остальные профили — основа для будущих редакторов.

## Запуск в Codex

Склонируйте репозиторий и откройте его папку в Codex. Skill находится в `.agents/skills/akb48-video-subtitles/` и доступен как проектный skill. Для использования в других проектах скопируйте эту папку в каталог пользовательских skills Codex: обычно `%USERPROFILE%\.codex\skills\akb48-video-subtitles` в Windows или `$CODEX_HOME/skills/akb48-video-subtitles`, если задан `CODEX_HOME`. После установки начните новую сессию.

Вызовите `$akb48-video-subtitles` или попросите Codex перевести/проверить ролик AKB48, указав язык и нужные файлы. Передайте локальное видео либо разрешённый источник, список участников и имён (если есть) и желаемые форматы. Для описанного процесса API-ключ не нужен.

## Быстрый запуск

Нужны Python 3.11+, FFmpeg и FFprobe. Для ASS требуется сборка FFmpeg с libass. Установите FFmpeg через пакетный менеджер вашей ОС и добавьте `ffmpeg` и `ffprobe` в `PATH`.

```powershell
python .agents/skills/akb48-video-subtitles/scripts/check_environment.py
python .agents/skills/akb48-video-subtitles/scripts/check_srt.py путь\к\субтитрам.srt
```

Дополнительные пакеты Python не нужны. См. [требования к ресурсам](.agents/skills/akb48-video-subtitles/references/resources.md).

## Процесс

1. Сверить японскую речь и отдельно собрать надписи, заголовки, правила и результаты.
2. Перевести по выбранному языковому профилю и проверенному словарю выпуска.
3. Подписывать говорящего только при достаточных основаниях; сомнительные реакции оставлять нейтральными.
4. Подготовить SRT, ASS и/или MP4 по запросу.
5. Проверить кадры по ролику и готовый рендер, тайминги, архив и сохранность звука.

Подробности: [процесс](.agents/skills/akb48-video-subtitles/references/workflow.md), [языковые профили](.agents/skills/akb48-video-subtitles/references/languages/README.md).

## Ресурсы

Для типичного ролика 1080p длительностью 20–40 минут ориентир — 8 ГБ памяти и современный 4-ядерный процессор. Для локального распознавания речи комфортнее 16 ГБ и 6–8 ядер. Оставьте примерно 10 ГБ свободного места на исходник, промежуточные файлы, рендер и резервную копию. Видеокарта необязательна. Для 4K и высокого битрейта может потребоваться больше ресурсов. Это оценка, фактическое потребление зависит от кодека, модели распознавания и энкодера.

## Права и конфиденциальность

Обрабатывайте и публикуйте только материалы, которые разрешено использовать. Не добавляйте в публичные pull request локальные расшифровки выпусков, полные субтитры, ключи, куки и личные словари без разрешения на распространение. Иллюстративные кадры показывают оформление; права на программу остаются у правообладателей.
