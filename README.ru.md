# Skill для субтитров AKB48

[English](README.md) · [Русский](README.ru.md) · [한국어](README.ko.md) · [Español (LatAm)](README.es-419.md) · [Bahasa Indonesia](README.id.md) · [ไทย](README.th.md) · [简体中文](README.zh-Hans.md) · [繁體中文](README.zh-Hant.md)

Открытый процесс в формате [Agent Skills](https://agentskills.io) для **Codex**, **DeepSeek Harness**, **Claude Code** и других совместимых хостов.

Повторяемый процесс перевода роликов AKB48 и 48 Group: отдельный учёт диалогов, авторства реплик, песен и надписей; сверка имён; подготовка SRT/ASS и проверка вшитого видео.

В репозитории есть пакет Agent Skills, стартовые языковые профили, проверка SRT, инструкции по запуску и два примера оформления из последних русских выпусков. Русский профиль основан на обработке полных выпусков. Корейский профиль пока требует проверки носителем; остальные профили — основа для будущих редакторов.

## Совместимость

Skill следует открытому формату [Agent Skills](https://agentskills.io): папка с `SKILL.md` (frontmatter `name` и `description`) и необязательными `scripts/`, `references/`, `assets/` и `glossaries/`. Зависимостей от конкретного хоста нет: все инструменты — Python стандартной библиотеки.

| Хост | Где находится skill | Как вызвать |
|---|---|---|
| **Codex** (CLI, IDE, ChatGPT desktop) | `.agents/skills/` в репозитории (Codex просматривает от рабочего каталога вверх до корня репозитория), `~/.agents/skills/` или каталог skills хоста | `$akb48-video-subtitles` в промпте или `/skills` |
| **DeepSeek Harness** | `<проект>/.agents/skills/`, `<проект>/.dsh/skills/`, `~/.dsh/skills/` или `~/.agents/skills/` | `/akb48-video-subtitles` в поле ввода или выбрать из меню `/` |
| **Claude Code** | `.claude/skills/` в проекте или `~/.claude/skills/` (скопировать или сделать symlink; Claude Code не сканирует `.agents/skills`) | `/akb48-video-subtitles` |
| **Другие клиенты Agent Skills** | каталог skills соответствующего хоста | по правилам хоста; skill использует только стандартные поля `name`/`description` |

Примечания:

- Обязательны только стандартные поля frontmatter. Специфичные для хоста дополнения (`agents/openai.yaml` для Codex/ChatGPT, `user-invocable`/`disable-model-invocation` в DeepSeek Harness) необязательны и игнорируются хостами, где их нет.
- Совместимость с DeepSeek Harness проверена на его файловом провайдере skills: папка находится в `.agents/skills`, загружается тот же `SKILL.md`, вызов — `/akb48-video-subtitles`. Переделка и правки кода не нужны.
- Claude Code использует другой каталог, но формат `SKILL.md` и скрипты те же; достаточно копии или symlink.
- Скрипты работают в Windows, macOS и Linux на Python 3.11+. Для вшивания видео нужны FFmpeg/FFprobe с libass, а пресет `episode-12` рассчитан на шрифт Segoe UI Semibold (переопределяется полем `font` в `presentation.json` или `--font` в `render_style_previews.py`).

## Краткая установка

Нужны Git, Python 3.11+, FFmpeg/FFprobe с libass и совместимый хост (Codex, DeepSeek Harness, Claude Code или другой клиент Agent Skills). Команды клонируют репозиторий и проверяют инструменты; сами зависимости ими не устанавливаются. Откройте клонированную папку в вашем хосте и начните новый чат.

```sh
git clone https://github.com/ivst/akb48-video-subtitle-codex-skill.git
cd akb48-video-subtitle-codex-skill
python .agents/skills/akb48-video-subtitles/scripts/check_environment.py --require-ass
```

## Глоссарии имён для восьми языков

В каталог skill включены словари `glossaries/members/{locale}.csv` для русского, английского, корейского, испанского (Латинская Америка), индонезийского, тайского и двух вариантов китайского. Они устанавливаются вместе со skill, даже если вы копируете только его папку.

**Русский словарь:** 83 имени сохранены в точности из предоставленного `member_names.ja-ru.json`. В комплекте также есть совместимая JSON-версия `glossaries/member_names.ja-ru.json`. Английский: 45 официальных латинских написаний и ещё 38 исторических имён, требующих проверки. Корейский и традиционный китайский: по 83 справочных написания из сообществ; упрощённый китайский: 83 черновых написания, требующих вычитки. Испанский и индонезийский используют латинские резервные написания. Проверенные тайские написания пока не добавлены.

У каждой записи есть статус проверки, источник и оценка уверенности. **Наличие записи не означает, что её проверил носитель языка.** Приоритет имеют имена из глоссария конкретного выпуска, переданного пользователем. Подробнее: [покрытие и правила](.agents/skills/akb48-video-subtitles/glossaries/README.md).

```powershell
python .agents/skills/akb48-video-subtitles/scripts/lookup_member.py --locale ru "武藤小麟"
```

Поиск поддерживает варианты японских иероглифов из таблицы алиасов, строгий режим `--strict` и явно обозначенную латинскую замену `--allow-fallback`. Непроверенные тайские и другие имена автоматически не придумываются. Список включает и представительниц сестринских групп (например, бывшую участницу NGT48 荻野由佳), поэтому не является точным списком выпускниц AKB48.

## Процесс

1. Сверить японскую речь и отдельно собрать надписи, заголовки, правила и результаты.
2. Перевести по выбранному языковому профилю и проверенному словарю выпуска.
3. Подписывать говорящего только при достаточных основаниях; сомнительные реакции оставлять нейтральными.
4. Подготовить SRT, ASS и/или MP4 по запросу.
5. Проверить кадры по ролику и готовый рендер, тайминги, архив и сохранность звука.

Подробности: [процесс](.agents/skills/akb48-video-subtitles/references/workflow.md), [языковые профили](.agents/skills/akb48-video-subtitles/references/languages/README.md).

## Ресурсы

Для типичного ролика 1080p длительностью 20–40 минут ориентир — 8 ГБ памяти и современный 4-ядерный процессор. Для локального распознавания речи комфортнее 16 ГБ и 6–8 ядер. Оставьте примерно 10 ГБ свободного места на исходник, промежуточные файлы, рендер и резервную копию. Видеокарта необязательна. Для 4K и высокого битрейта может потребоваться больше ресурсов. Это оценка, фактическое потребление зависит от кодека, модели распознавания и энкодера.

## Контроль русского перевода

Добавлены проверка оставшегося японского текста, минимальной/максимальной длительности, допустимых перекрытий и обратная проверка написаний участниц. Для русского профиля **700 мс — минимальный ориентир**, **900 мс — предпочтительная длительность** (не универсальное правило). CPS включает видимые пробелы.

```powershell
python .agents/skills/akb48-video-subtitles/scripts/check_srt.py examples/quality/ru.srt --profile ru --duration 14 --json
python .agents/skills/akb48-video-subtitles/scripts/check_names.py --source examples/quality/ja.srt --target examples/quality/ru.srt --episode examples/quality/episode.json --json
```

Проверки японского письма эвристические: иероглифы допустимы в китайском, а названия песен и имена могут сохраняться на японском. Настройки: `--strict-japanese`, повторяемый `--allow-japanese`, `--allow-overlap`. `check_names.py` учитывает временные интервалы и варианты имён. Пропуск полного имени считается предупреждением (местоимение может быть переводчески правильным), запрещённые варианты — ошибкой.

## Контракт перевода и проверяемый отчёт

Для длинного выпуска добавлен [протокол перевода](.agents/skills/akb48-video-subtitles/references/translation-protocol.md): чанки примерно по 40–60 реплик, одинаковые ID и порядок в исходном и переводном JSON, отсутствие пустых переводов. Разделение или объединение финальных титров допустимо уже после проверки чанков.

```powershell
python .agents/skills/akb48-video-subtitles/scripts/check_translation.py --input examples/quality/source.json --translated examples/quality/translated.json --target-lang ru --json
python .agents/skills/akb48-video-subtitles/scripts/init_project.py --project my-episode --episode-id episode-001 --locale ru
python .agents/skills/akb48-video-subtitles/scripts/run_checks.py --project my-episode --require-translation
```

Рабочая папка содержит `episode.json`, `source/`, `work/chunks/`, `output/`, а после запуска проверок — `report.json`. Последний фиксирует **реально исполненные** команды, коды завершения и SHA256; отсутствующие данные отражаются как `not_run`, а не как пройденные проверки.

## Рекомендованная модель и финальные проверки

Для сложного перевода с японского **рекомендуется GPT-6.1 Sol с уровнем рассуждений Medium и выше**, если модель доступна. Это рекомендация, не обязательная зависимость и не гарантия лучшего перевода. Спорные реплики, каламбуры, имена и интонации всё равно необходимо сверять с японским аудио.

Добавлены `check_ass.py` для структуры ASS, `probe_media.py` для метаданных видео, `compare_media.py` для сверки исходного и готового файла и `compare_audio.py` для сравнения **декодированного PCM**, а не исходных сжатых аудиопакетов. Инструментам видео требуются FFmpeg/FFprobe. Полный [Definition of Done](.agents/skills/akb48-video-subtitles/references/deliverables.md) и [история изменений](CHANGELOG.md). Версия репозитория: [VERSION](VERSION).

## Названия песен: латиница вместо смыслового перевода

В справочнике 78 названий: заглавные треки инди-релизов и синглов 1–68, а также семь выбранных сценических, альбомных и дополнительных песен. У каждой записи есть источник; это ещё не полный каталог всех песен AKB48.

Название песни — **собственное имя**, а не реплика или строка песни, которую следует переводить. Для оригинальных песен AKB48 сохраняем принятое **латинское название / ромадзи** на всех восьми языках: `愛の意味を考えてみた` → **Ai no Imi wo Kangaete Mita**, а не «Размышления о смысле любви»; `恋するフォーチュンクッキー` → **Koi Suru Fortune Cookie**; `ヘビーローテーション` → **Heavy Rotation**. Если речь об официальном локализованном кавере сестринской группы, используем официальное название **именно этой версии**. При этом текст песни, в отличие от её названия, переводится при необходимости.

Приоритет: написание на официальном релизе/сайте лейбла → AKB48 Wiki → другой профильный Wiki; утверждённый глоссарий конкретного выпуска имеет преимущество. В отдельном `glossaries/songs.csv` пока **5 подтверждённых источниками справочных записей** с указанием статуса, а не вся дискография. Неизвестные названия нельзя транслитерировать по догадке или заменять английским переводом смысла. Подробности: [правила названий песен](.agents/skills/akb48-video-subtitles/glossaries/songs/README.md).

```powershell
python .agents/skills/akb48-video-subtitles/scripts/lookup_song.py "愛の意味を考えてみた"
python .agents/skills/akb48-video-subtitles/scripts/check_song_titles.py --input examples/quality/song_source.json --translated examples/quality/song_translated.json --strict --json
```

Для достоверной проверки указывайте `song_ids` в исходных JSON-чанках. Совпадение японской строки с названием без такого указания даёт предупреждение, а не ошибку: это может быть обычная реплика или слова песни.

## Полная проверка видео

В отчёт для видеорезультата включено полное программное декодирование исходника и результата, проверка ошибок декодера и совпадения фактического числа кадров (`check_decode.py`). Хеширование аудио защищено от блокировки потоков и ограничено тайм-аутом на весь процесс. Параметр `run_checks.py --media-timeout 1800` задаёт максимум секунд на файл. Сравнение кадров предполагает отсутствие намеренного изменения частоты кадров.

## Whisper и подробное руководство

**faster-whisper** можно использовать для японской расшифровки и перепроверки субтитров. Перевод и установление говорящих выполняются отдельно. Это необязательная зависимость с отдельным окружением; CPU-вариант не требует WSL или GPU. См. [установку и пример распознавания](.agents/skills/akb48-video-subtitles/references/transcription.md) и [подробное руководство на русском](docs/workflow.ru.md): надписи, говорящие, оформление, сборка и проверки с переносимыми путями и честным описанием ограничений.

## Говорящие и компактное оформление (0.5.0)

Для ASS/видео теперь нужна проверенная `work/presentation.json`. Сборщик `build_presentation.py` и проверка `check_presentation.py` обеспечивают имена/роли, раздельные реплики и отдельные плашки надписей. Неизвестные голоса автоматически не объединяются. Нижний отступ по умолчанию — 30 логических px на 1080p, то есть 20 px на 720p. Фоновые и концертные песни пропускаются без явного запроса. Старые проекты без разметки получают incomplete. См. [схему и команды](.agents/skills/akb48-video-subtitles/references/presentation.md) и [синтетическое превью](examples/compact-preview.jpg) нового оформления; кадры программы служат исходными референсами оформления.
